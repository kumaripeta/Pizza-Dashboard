# 🍕 Pizza Sales Report Dashboard (Power BI,Excel,SQL)

## 📌 Project Overview

This project is an interactive **Pizza Sales Dashboard** built using **Power BI** to analyze sales performance, customer ordering behavior, and business trends over a one-year period.

The dashboard helps stakeholders understand key metrics like revenue, order patterns, and product performance to support data-driven decision-making.

---

## 📊 Key Features

### 🔹 KPIs (Key Performance Indicators)

* **Total Revenue:** 817.86K
* **Average Order Value:** 38.31
* **Total Pizzas Sold:** 49,574
* **Total Orders:** 21,350
* **Average Pizzas per Order:** 2.32

---

### 🔹 Sales Insights

* **Busiest Days:** Weekends (Friday & Saturday evenings)
* **Peak Months:** January and July
* **Top Category:** Classic pizzas contribute the highest sales
* **Top Size:** Large pizzas generate maximum revenue

---

### 🔹 Visualizations Included

* 📈 Daily Trend for Total Orders
* 📊 Monthly Trend for Orders
* 🍕 Sales Distribution by Category
* 📏 Sales Distribution by Pizza Size
* 🏆 Total Pizzas Sold by Category

---

## 🧰 Tools & Technologies Used

* **Power BI,Excel,SQL** – Data visualization & dashboard creation
* **Excel / CSV Dataset** – Data source
* **DAX (Data Analysis Expressions)** – Calculations & measures
* **Data Cleaning** – Performed before visualization

---

## 🧹 Data Preparation Steps

* Removed duplicates and null values
* Standardized column formats
* Created calculated columns & measures using DAX
---


## 📌 Business Insights

* Weekend demand is significantly higher → optimize staffing & inventory
* Large pizzas are most preferred → focus promotions here
* Classic category dominates → maintain quality & availability
* Seasonal trends observed → plan marketing campaigns accordingly
